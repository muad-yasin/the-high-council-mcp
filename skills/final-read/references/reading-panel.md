# The reading panel - four stances, checkable questions

Answer the questions. If an answer starts sounding like appreciation, it has stopped being an answer. The diagnostics named here are defined in `line-editing` - run them from there, not from memory of them.

## 1. The professional reader

*Would a real outlet publish this, and did the point land without being pointed at?*

- Wire test, per layer: straight news is right for the first line and wrong for a body sentence.
- Name the argument (or the joke) in one line. If you can't, either the piece is honest routine material - fine, say so - or the point isn't there. **If a voice in the copy named it for you, that's the explanation failure.**
- Read the first layer as it is actually met: with its surrounding interface, once, at the size it renders.

## 2. The ordinary reader

*Do I want to read this, and will I want the next one?*

- Would you open it? **Say why in five words.** "I want to know if this affects my account" is a reason; "it sounds important" is not.
- Name the sentence where you wanted to stop. If there isn't one, say so. If there is, that sentence is the finding.
- **The keeper:** what would you retell someone afterwards? A piece with no keeper has no reason to be its length.
- **Boredom is cumulative - ask across the batch.** After reading them all in a row, would you open the next one? This is where sameness shows even when every item passes alone.

## 3. The QA reader

*Does every layer earn its place?*

- Layer test at every junction: name what each layer adds that the one above didn't. **A layer with no answer is a rewording.**
- Wall check: a body over ~70 words as one block - say where it turns. **If you can't name a turn, that is the finding**; the problem is the argument, not the whitespace.
- Deletion test on the **first** sentence only.
- Ending test: name the feeling a reader has on first hearing this, then read the last sentence alone. Does it confirm that feeling, or explain something? Explanation fails, and so does a qualifier trailing after the sting.
- Counts and fingerprints run as a script, not as reading. Across the batch, watch what a script can't count: one argumentative move opening three pieces, one verb owning every headline.

## 4. The owner's proxy

*Does it say what it means, and does it hold the house line?*

- Distillation test: state in one sentence what the piece *argues*. A restatement of the event means no stance - automatic `fix`.
- Is the point made in plain words, with the force carried by the choice and phrasing of facts rather than by a narrator instructing the reader? **Would it read the same if the writer were indifferent?**
- The standing house rules, checked rather than assumed - every project has a short list (conflict neutrality, name handling in satire, frozen text untouched, register-specific vetoes). This is the last desk before sign-off.
- **A proposed consequence** - a rating, a recommendation, a price, a call to action - read against the piece *as written*, not as researched. A consequence that doesn't follow from the piece is a finding. Name the mismatch; propose nothing.
- **Know which half is yours.** Where a house rule fixes the *direction* of a consequence by a stated principle, direction isn't this desk's to re-argue - only magnitude is. This pass carries the authority of independent review, so a reviewer armed with a retired or private version of a rule doesn't just miss defects; it raises findings against correct work and pushes the wrong model back upstream. **When the house rule and your own reasoning disagree, the disagreement is the finding.** Say so; never silently adopt your own version.
